# Design specification
Full control dashboard based on concept.png. White panels on #f5f6f8, navy text, blue primary, red immediate software stop. Left 190px rail, two-column 1.55:1 workspace, three equal camera frames, telemetry table, controls above inference form, full-width event log. System Chinese sans, 32px heading, 14px body, tabular numerals. 8px corners, 1px cool-gray borders, no large shadows.
Intentional corrections to generated concept: remove invented slogan, task/model/recording/settings navigation (not requested); replace hallucinated joint ranges with actual config values; add separate camera start/stop and device release controls necessary for real ownership; show real offline/fault/stop-latched state, operator confirmation dialog, diagnostic output and demo mode label. No fabricated telemetry on hardware mode.
Responsive: rail becomes top bar below 900px, columns stack, cameras stack below 560px, stop remains sticky at top. Icons use lucide outline, 18px in controls. All control text is code-native.
